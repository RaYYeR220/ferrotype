One read, checked three ways.

The same Fe verifier checks it in this tab as WebAssembly and on Sepolia as a contract. Beside them, the native CLI’s runs on the same files, with each file to run it yourself. No wallet, no install.

Saved from Ethereum mainnet with eth_getProof. The native CLI was run on each file and on its damaged copies: 20 runs, recorded with Fe 26.6.0 (5b3f96a).
